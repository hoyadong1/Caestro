✏️ 악보 직접 고치기 (고급)

위에서 만든 곡이 악보 표기로 들어 있습니다. 한 칸은 16분음표, 4/4박자 한 마디는 16칸, 3/4박자는 12칸이고 |는 마디선입니다. 고치면 바로 검사하고 미리 듣기에 반영됩니다.

코드 진행 예: C:16 | F:8 C:8 · C Cm C7 Cmaj7 Cm7 Cm6 C6 Cdim Cdim7 Caug Csus4, 자리바꿈 F/C

선율 E5:4 음:길이 · r 쉼표 · - 붙임줄
