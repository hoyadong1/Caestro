CAESTRO STUDIO

악보와 악기는 차 밖에서 만듭니다

카에스트로 스튜디오는 차에 넣을 곡과 악기를 만드는 웹 플랫폼입니다. 여기서 만든 악보와 악기는 클라우드에 올라가고, 차는 정차 중에 골라 내려받기만 합니다. 앱이 쓰는 것과 같은 규칙으로 바로 검사하고, 속도를 올려 가며 미리 들어 볼 수 있습니다.

악보

한 칸은 16분음표입니다. 4/4박자 한 마디는 16칸, 3/4박자는 12칸. |는 마디선이고 위치가 맞는지 검사합니다.

코드 진행 예: C:16 | F:8 C:8 | G7:8 C:8 · 쓸 수 있는 코드: C Cm C7 Cmaj7 Cm7 Cm6 C6 Cdim Cdim7 Caug Csus4, 자리바꿈 F/C

선율 예: E5:6 G5:2 G5:8 | r:4 D5 - C5 · r 쉼표, - 붙임줄, :n 길이(칸)

보이싱 직접 쓰기 (선택)

코드마다 실제로 누를 음을 낮은 음부터 적습니다. 코드 수와 같아야 합니다. 예: C3 E3 G3 C4 E4 | C3 D3 A3 D4 F4

악기

한 음씩 녹음한 파일(WAV·MP3·M4A)을 여러 개 올립니다. 파일 이름에 음 이름(C4, A#3)이 있으면 그대로 쓰고, 없으면 음높이를 찾아냅니다. 24 kHz로 바꾸고 앱의 악기와 같은 크기로 맞춥니다. 지속음은 1.6초 이상이면 끊김 없이 이어지는 루프를 만듭니다.

배음(기본음의 몇 배 높이), 크기, 울림 길이를 정해 음색을 만듭니다. 음역 안에서 장3도마다 한 음씩 만들어 담습니다.

① 악보나 ② 악기 탭에서 “클라우드 팩에 담기”를 누르세요.
올리는 방법 (프로토타입)

이 시연용 클라우드는 GitHub Pages(docs/cloud)라서, 받은 zip을 저장소의 docs/cloud에 풀고 올리면 됩니다. 실제 서비스에서는 이 단계가 업로드 버튼 하나이고, 운영자가 저작권을 확인한 뒤 카탈로그에 공개합니다. 차는 클라우드 탭에서 새 목록을 받아, 정차 중에만 내려받습니다. 차가 재생할 수 없는 팩은 설치하지 않고 이전 것을 지킵니다.

카에스트로 스튜디오 프로토타입 · 팩 형식은 저장소의 tools/cloud/README.md를 따르고, 검사는 차 앱의 규칙(CloudLibrary)과 같습니다. 이 페이지는 아무것도 서버로 보내지 않습니다: 모든 처리는 브라우저 안에서 합니다.
